# Signal Processing Tools

A Python package for generating, modifying, and visualizing basic signals.

## Signal Generation
- **Sine waves** – `make_sine()`
- **Square waves** – `make_square()`

## Signal Operations
- **Time shifting** – `shift_time()`
- **Time scaling** – `scale_time()`

## Visualization
- Original vs. shifted vs. scaled plots saved as PNG.
