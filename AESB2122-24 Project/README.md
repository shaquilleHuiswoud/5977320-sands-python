\# Signal Processing Tools



A Python package for generating, modifying, and visualizing basic signals.  

Developed as part of the AESB2122-24 Signals and Systems course project at TU Delft.



---



\## Signal Generation



\- \*\*Sine waves\*\* – Standard sinusoidal signals using `make\_sine()`

\- \*\*Square waves\*\* – Binary amplitude signals with sharp transitions using `make\_square()`



---



\## Signal Operations



\- \*\*Time shifting\*\* – Delay or advance signals in time using `shift\_time()`

\- \*\*Time scaling\*\* – Stretch or compress signals in time using `scale\_time()`



---



\## Visualization



\- Side-by-side comparison plots (original vs. shifted vs. scaled signals)

\- Matplotlib-based plotting with customizable layouts

\- Saved figures as `.png` images for easy inspection and reporting
